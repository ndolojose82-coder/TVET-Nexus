Common mistakes

  • Using = (assign) instead of == (compare) inside an if.
  • Forgetting the & in scanf for numbers.
  • Array positions start at 0, so marks[5] is outside a 5-element array.
  • Integer division drops the decimal part: 5 / 2 is 2.
  • Missing semicolon ; at the end of a statement.

SQL (Database Management)

CREATE TABLE students (
            id INT PRIMARY KEY,
            name VARCHAR(50),
            marks INT
        );

        INSERT INTO students (id, name, marks) VALUES (1, 'Amina', 78);

        SELECT name, marks FROM students
        WHERE marks > 70
        ORDER BY marks DESC;

        UPDATE students SET marks = 80 WHERE id = 1;
        DELETE FROM students WHERE id = 1;

        ALTER TABLE students ADD email VARCHAR(100);

Process states

New → Ready → Running → Waiting (blocked) → Terminated. A running process goes back to Ready when its time slice ends.

NOT flips a single input: NOT 0 = 1 and NOT 1 = 0.

Boolean laws

  • A AND 0 = 0, A AND 1 = A, A AND A = A, A AND (NOT A) = 0
  • A OR 0 = A, A OR 1 = 1, A OR A = A, A OR (NOT A) = 1
  • De Morgan: NOT (A AND B) = (NOT A) OR (NOT B), and NOT (A OR B) = (NOT A) AND (NOT B)

Sets

Union A ∪ B: in A or B. Intersection A ∩ B: in both. Complement: not in A. A set lists each element once.

Statistics and probability (Quantitative Analysis)

MeasureFormula or meaning
MeanSum of values ÷ number of values
MedianMiddle value when ordered (average the two middle values if the count is even)
ModeMost frequent value
RangeLargest value − smallest value
VarianceAverage of the squared differences from the mean
Standard deviationSquare root of the variance. For a sample, divide by n − 1

Probability

  • P(event) = favourable outcomes ÷ total outcomes, and always lies between 0 and 1.
  • P(not A) = 1 − P(A).
  • Mutually exclusive events: P(A or B) = P(A) + P(B).
  • Independent events: P(A and B) = P(A) × P(B).

Example: mean of 4, 6, 8, 10, 12 is 40 ÷ 5 = 8.
